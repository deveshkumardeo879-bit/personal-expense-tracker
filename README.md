# Personal Expense Tracker Using Python

## Project Overview

Personal Expense Tracker is a simple command-line Python application that helps users record and manage their daily expenses.

The user can add an expense by entering the amount, category, description, and date. The application can also display saved expenses, calculate total spending, and show spending by category.

## Features

- Add a new expense
- View all recorded expenses
- Calculate total expenses
- View expenses by category
- Save expense records in a CSV file
- Handle invalid input
- Simple command-line interface

## Technologies Used

- Python 3
- Python Standard Library
- CSV file handling

## Requirements

Python 3.x is required to run this project.

No external Python packages are required.

## How to Run

1. Open the PersonalExpenseTracker folder in Visual Studio Code.
2. Open the VS Code terminal.
3. Type the following command:

python main.py

4. Press Enter.

## How to Use

When the program starts, it shows a menu:

1. Add Expense
2. View Expenses
3. Total Expenses
4. Category Summary
5. Exit

Choose a number from 1 to 5.

To add an expense, enter the amount, category, description, and date.

The expense information is saved automatically.

## Data Storage

The expense records are stored in a CSV file named expenses.csv.

The file is created automatically when the first expense is added.

## Error Handling

The program checks the entered amount and handles invalid numerical input.

## Future Improvements

The project can be improved by adding monthly reports, budget tracking, data visualization, database storage, and a graphical user interface.
